Arc is an EVM-compatible Layer-1 blockchain built by **Circle** (the company behind USDC). Designed as an "Economic Operating System for the Internet" — stablecoin-native gas fees, sub-second finality, institutional-grade privacy tools.

- Public testnet launched: **October 2025**
